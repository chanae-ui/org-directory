# Web - אלפון ארגוני (בקרוב)

תיקייה זו עדיין ריקה. השלב הבא בפרויקט (אחרי שה-Backend רץ ומסנכרן נתונים אמיתיים) הוא ליצור כאן אפליקציית React עם:

- קריאות ל-API של ה-Backend (`GET /api/contacts`)
